These are the finished website files, ready for GitHub Pages.

## Make it live on GitHub Pages
1. Upload everything in this folder to the **main (root) folder** of your GitHub repository
   (`index.html` must be at the top level, not inside another folder).
2. In the repository go to **Settings → Pages**.
3. Under **Build and deployment** choose **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)**, then **Save**.
4. Wait 1–2 minutes and open the link GitHub shows at the top of the Pages settings.
